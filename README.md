# Hola, soy Damián 👋

Desarrollador full-stack de Chile (Android, iOS y web). Me dedico a construir herramientas que conectan a los agentes de código con el mundo real, y a que usarlos sea más barato y menos frágil.

## Lo que estoy construyendo

| Proyecto | Qué hace |
|---|---|
| 🔀 **[claude-switch](https://github.com/Drozast/claude-switch)** | Cambia entre Claude (suscripción) y cualquier otro modelo —local, en tu red o por API— en Claude Code con un clic, sin cerrar la sesión. Un proxy y un modo por ventana de VS Code. |
| 💬 **[waat](https://github.com/Drozast/waat)** | WhatsApp Agent Toolkit: vincula tu WhatsApp una vez y deja que opencode o Claude Code lean y escriban conversaciones (MCP). Todo local. |
| 🌐 **[supertools-mcp](https://github.com/Drozast/supertools-mcp)** | Plugin MCP para publicar y administrar sitios web de Supertools desde tu asistente de IA. |
